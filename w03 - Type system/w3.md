# 3\. hét: A típusrendszer

# W3T1: Ismerkedjünk meg a `serde`-vel
- A Serde egy keretrendszer, ami általános én hatékonyan tud **ser**ializálni és **de**serializálni struktúrákat
- Rengeteg célformátum van, a legismertebbek a JSON, YAML, TOML, és a BSON, de több bináris formátumot is támogat (pl. Postcard)
- Készítsünk egy új projektet, majd hozzunk létre legalább 2 saját struktúrát, majd a `#derive` attribútum segítségével imlementáljuk a `serde` `Serialize` és `Deserialize` trait-jeit

Informális követelményspecifikáció: a programunk felhasználókat, és a felhasználókhoz tartozó szerszámokat tárol. A felhasználók és a szerszámok is rendelkeznek azonosítóval (ez lehet inkremenális azonosító, Guid, vagy akár String is), és névvel is (String). A felhasználók tárolják a szerszámaikat egy belső vektorban, amely szerszámokat tárol.
A feladat akkor tekinthető késznek, ha egy felhasználókat tartalmazó vektorban legalább 2 felhasználó, legalább 1-1 szerszámmal létrejön, és a felhasználókból álló vektort a program JSON formátumban el tudja menteni, majd abból vissza is tudja azt állítani.



# W3T2/A1: Az egyik legnépszerűbb Prog 1 házi

- Az előadás hátra lévő részében készíts egyszerű raktárkezelőt
  - Használhatod a [`clap`](https://docs.rs/clap/latest/clap/) könyvtárat CLI argumentumok feldolgozására
  - Használj saját struktúrákat az adatmodellhez
  - Tárold a bejegyzéseket structokat tároló vectorokban, a Serde segítségével szerializáld, majd mentsd fájlba az adatokat
    - A választott formátum tetszőleges, de javasolt a JSON használata
- Az A1 alfeladat: a megvalósított rendszer adatmodellje tegye azt alkalmassá adatbázisokkal való használatra (a feladatnak nem része konkrét adatbázis csatolása, ez a későbbi hetekben sorra kerül majd)

Informális követelményspecifikáció: A program tároljon felhasználókat, tárolási helyeket, és elemeket. Az elemek egymásba ágyazása tetszőleges, az A1 pontok megszerzéséhez viszont szükséges a sémadekompozíció átgondolása, és megfelelő séma kialakítása (továbbra is tetszőleges szerializációval tárolva).
